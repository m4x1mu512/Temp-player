# Настройка выбора неоновых акцентных цветов интерфейса (Киберпанк)

Добавление в настройки приложения возможности выбора акцентного цвета оформления из палитры «неоновый киберпанк», применяемого ко всем кнопкам, вкладкам, слайдерам, индикаторам и активным элементам пользовательского интерфейса.

### User Review & Critical Decisions

> [!IMPORTANT]
> Решения, согласованные с пользователем:
> - **Цветовая палитра**: Набор ярких «неоновых киберпанк» оттенков:
>   1. **Неоновый бирюзовый (Neon Turquoise)** — фирменный кибер-акцент по умолчанию
>   2. **Электрик фиолетовый (Electric Purple)** — глубокий сияющий пурпур
>   3. **Кибер-жёлтый (Cyber Yellow)** — высококонтрастный золотисто-неоновый
>   4. **Неоновый розовый (Neon Pink / Magenta)** — ультра-розовый акцент
>   5. **Матричный зеленый (Matrix Green / Toxic)** — кислотно-зеленый неоновый оттенок
>   6. **Неоновый оранжевый (Neon Orange)** — яркий закатный импульс
>   7. **Электрик синий (Electric Blue)** — холодный лазерный синий
> - **Область применения**: Ко всем кнопкам, вкладкам, ползункам прогресса/громкости, чипам фильтрации, бейджам и индикаторам активных треков.
> - **Визуальное оформление в настройках**: Горизонтальный ряд круглых цветных кружков с мягким свечением и галочкой выбора активного цвета.

---

### 1. Overview & Core Concept

- **Что делает**: Предоставляет пользователю возможность персонализировать цветовую гамму приложения под свое настроение или стиль треков, мгновенно переключая системный `primary` и `secondary` цвет всей дизайн-системы Material Design 3.
- **Сохранение состояния**: Выбор сохраняется в `SettingsDataStore` (и кэшируется в `SharedPreferences` для исключения мигания при холодном старте приложения).

---

### 2. User Experience & Visual Design

- **Экран настроек**:
  - В секции «Оформление» под карточкой темы появляется карточка «Акцентный цвет интерфейса».
  - Отображается горизонтальный ряд крупных круглых палитр (минимальный touch-target 48dp).
  - Выбранный цвет отмечен контрастной галочкой по центру и светящейся обводкой.
  - Под каждым кружком указано название цвета.
- **Отклик интерфейса**:
  - При нажатии на цвет вся тема приложения мгновенно перестраивается: основные кнопки (Play/Pause, FAB, иконки действий), полосы прогресса, ползунки эквалайзера, выделение играющего трека и активные вкладки моментально меняют цвет.

---

### 3. Key Product Decisions & Trade-Offs

- **Решение 1: Динамическое построение MaterialTheme ColorScheme**:
  - *Выбранный подход*: В `MyApplicationTheme` подставлять выбранный `AccentColor` в качестве основы `primary`, `secondary` и связанных тональных контейнеров для светлой и темной тем.
  - *Преимущество*: Не требуется вручную прокидывать цвет в каждый отдельный Composable — вся инфраструктура Jetpack Compose Material 3 подхватывает его автоматически.
- **Решение 2: Синхронный кэш на холодный запуск**:
  - *Выбранный подход*: Сохранение выбранного `AccentColor.name` в кэш `SharedPreferences` аналогично существующему `ThemeMode`, чтобы при запуске приложения цвет активировался мгновенно без мерцания стандартного цвета.

### 4. Technical Architecture & Data Strategy

```
┌────────────────────────────────────────────────────────────────────────┐
│                          SettingsScreen                                │
│                                                                        │
│   Карточка «Акцентный цвет»: круглые кружки с индикатором выбора       │
│   onClick -> viewModel.setAccentColor(accentColor)                     │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│                   SettingsDataStore & MainViewModel                    │
│                                                                        │
│   accentColorFlow: StateFlow<AccentColor>                              │
│   SharedPreferences кэш для старта без задержек                       │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│                         MyApplicationTheme                             │
│                                                                        │
│   darkColorScheme(primary = accent.darkPrimary, ...)                   │
│   lightColorScheme(primary = accent.lightPrimary, ...)                 │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│                   Все компоненты интерфейса приложения                 │
│                                                                        │
│   • Кнопки управления и FAB                                            │
│   • Слайдеры и полоса прогресса                                        │
│   • Активные вкладки и чипы                                            │
│   • Подсветка текущего трека в списках                                 │
└────────────────────────────────────────────────────────────────────────┘
```

#### Затронутые файлы:
1. `com/example/data/model/AccentColor.kt`: создание `enum class AccentColor` с палитрой неонового киберпанка и названиями.
2. `com/example/data/local/SettingsDataStore.kt`: добавление ключа preferences, кэширования и функций чтения/записи.
3. `com/example/ui/viewmodel/MainViewModel.kt`: экспонирование `accentColor: StateFlow<AccentColor>` и функции `setAccentColor`.
4. `com/example/ui/theme/Theme.kt`: обновление `MyApplicationTheme` с приемом `accentColor` и динамической адаптацией палитр.
5. `com/example/MainActivity.kt`: передача текущего `accentColor` из ViewModel в `MyApplicationTheme`.
6. `com/example/ui/screens/SettingsScreen.kt`: добавление карточки выбора акцентного цвета с круглыми цветными кружками и галочкой.

### План верификации
1. Компиляция через `compile_applet`.
2. Запуск локальных юнит-тестов `gradle :app:testDebugUnitTest`.
3. Проверка переключения акцентных цветов в настройках:
   - Изменение цвета активных кнопок, ползунков, вкладок и подсветки списка.
   - Сохранение выбранного цвета после перезапуска или возврата на главный экран.
