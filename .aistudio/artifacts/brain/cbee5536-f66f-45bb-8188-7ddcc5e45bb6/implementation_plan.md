# Устранение анимации перелистывания трека при изменении избранного

Устранение ложной анимации горизонтального перелистывания трека при нажатии на кнопку добавления/удаления из избранного в развернутом плеере, с добавлением плавной пружинной микроанимации сердечка.

### User Review & Critical Decisions

> [!IMPORTANT]
> Решения, согласованные с пользователем:
> - **Отсутствие анимации смены трека**: При нажатии кнопки «В избранное» трек обязан оставаться на месте; анимации скольжения обложки и названия полностью исключаются.
> - **Микроанимация кнопки избранного**: Плавная пульсация сердечка с пружинным эффектом (bouncy spring scale) и мягким переходом цвета в ярко-красный.
> - **Уведомления**: Без всплывающих Toast/Snackbar сообщений — только чистый визуальный отклик самой кнопки.

---

### 1. Overview & Core Concept

- **Причина проблемы**: Контейнеры обложки (`ExpandedSlidingArtwork`) и заголовка трека (`AnimatedContent`) использовали `targetState = track`. Так как модель `Track` является `data class` с полем `isFavorite: Boolean`, изменение статуса избранного создавало новый экземпляр `Track`, что приводило к неравенству объектов (`oldTrack != newTrack`). `AnimatedContent` ошибочно воспринимал это как смену песни и запускал горизонтальное скольжение влево/вправо.
- **Решение**: Привязать триггер смены трека в `AnimatedContent` к неизменяемому уникальному идентификатору `track.id`. Изменение свойств метаданных (таких как `isFavorite`) внутри текущей композиции больше не будет провоцировать анимацию перехода треков.

---

### 2. User Experience & Visual Design

- **Поведение при нажатии на сердечко**:
  1. Пользователь нажимает на иконку сердечка в развернутом плеере или мини-плеере.
  2. Обложка, заголовок и исполнитель остаются абсолютно статичными на экране — никакого смещения или перелистывания.
  3. Иконка сердечка совершает выразительную пружинную пульсацию (увеличение масштаба до ~1.25x с мягким затуханием до 1.0x).
  4. Цвет плавно анимируется от приглушенного серого к фирменному `FavoriteRed` (или обратно).

---

### 3. Key Product Decisions & Trade-Offs

- **Решение 1: Ключевание `AnimatedContent` по `track.id`**:
  - *Выбранный подход*: Перевести `AnimatedContent(targetState = track)` на `AnimatedContent(targetState = track.id)` во всех секциях развернутого плеера (обложка, заголовок в портретной и ландшафтной ориентациях). Внутри блока передавать актуальные данные через замыкание или получение трека.
  - *Преимущество*: 100% гарантия того, что анимация перелистывания активируется исключительно при физической смене воспроизводимого аудиофайла.
- **Решение 2: Пружинная анимация сердечка**:
  - *Выбранный подход*: Использование `animateFloatAsState` со спецификацией `spring(dampingRatio = Spring.DampingRatioMediumBouncy, stiffness = Spring.StiffnessMedium)` и `animateColorAsState` для плавной смены оттенка.
  - *Преимущество*: Мгновенный, приятный тактильный отклик без загромождения экрана всплывающими диалогами.

---

### 4. Technical Architecture & Data Strategy

```
┌────────────────────────────────────────────────────────────────────────┐
│                        User Taps Favorite Button                       │
│                                                                        │
│                viewModel.toggleFavorite(track.id)                      │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│           StateFlow update: isCurrentTrackFavorite toggles             │
│         (track.id остается неизменным, меняется только флаг)           │
└───────────────────┬────────────────────────────────┬───────────────────┘
                    │                                │
                    ▼                                ▼
┌──────────────────────────────────────┐ ┌───────────────────────────────┐
│ AnimatedContent(targetState=track.id)│ │     Favorite Heart Icon       │
│                                      │ │                               │
│ • ID совпадает -> Анимация НЕ играет │ │ • scale: spring pulse (1.25x) │
│ • Обложка и текст неподвижны         │ │ • color: smooth fade to Red   │
└──────────────────────────────────────┘ └───────────────────────────────┘
```

#### Затронутые компоненты:
1. `ExpandedSlidingArtwork`: замена `AnimatedContent(targetState = currentTrack)` на `AnimatedContent(targetState = currentTrack.id)`.
2. Портретный заголовок: замена `AnimatedContent(targetState = track)` на `AnimatedContent(targetState = track.id)`.
3. Ландшафтный заголовок: замена `AnimatedContent(targetState = track)` на `AnimatedContent(targetState = track.id)`.
4. Кнопки `mini_player_favorite` и `player_favorite_button`: добавление пружинной анимации масштаба (`scale`) и цвета (`animateColorAsState`).
